# Programs and source register

Program rules change. Recheck official sources at the time of every investigation; this file is a starting register, not standing authorization.

| ID | Source | Purpose |
| --- | --- | --- |
| S1 | Vendor security / vulnerability disclosure policy | Canonical reporting route and coordinated-disclosure expectations. |
| S2 | Current bounty-program brief | In-scope assets, exclusions, testing rules, rewards, and safe harbor. |
| S3 | Product terms and acceptable-use rules | Additional constraints on testing and automation. |
| S4 | Official pricing and billing documentation | Cost estimates and credit rules for paid testing. |
| S5 | Bugcrowd researcher reporting documentation | General report structure and evidence guidance. |
| S6 | Bugcrowd disclosure and safe-harbor documentation | General disclosure mechanics; program-specific terms still control. |
| S7 | Destination's current attachment/encryption instructions | Handling exact sensitive evidence when necessary. |

For each investigation, privately record URL, retrieval date, relevant quoted rule or paraphrase, and the resulting scope decision. A source register does not itself grant permission.
