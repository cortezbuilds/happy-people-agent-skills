# Scouting

This class contains skills that notice a bounded opportunity while the agent is doing some other useful work, capture only the evidence needed, and then return to the user's primary task.

## Included

- [OSS Contribution Scout](../../skills/oss-contribution-scout/SKILL.md)
- [Privacy Exposure Scout](../../skills/privacy-exposure-scout/SKILL.md)

Scouting skills must remain cheap in user attention and agent budget. They should not turn ordinary work into a standing audit, publishing campaign, or unrelated research project.

Class folders are indexes, not install targets. Install the skill folder beneath `skills/`.
